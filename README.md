## Email image URL

After uploading `website-concept.png` to a customer directory, embed its public URL in the email HTML:

```html
<img src="https://raw.githubusercontent.com/Jsxkami/uisome-customer/main/customers/degrace-plumbing/website-concept.png" alt="DeGrace Plumbing website concept" width="600" style="display:block;width:100%;height:auto;border:0;">
```

Note: GitHub raw URLs are suitable for testing; for reliable production email image delivery, use a dedicated CDN or Uisome-hosted asset URL. Do not publish private customer information or unverified claims.
